# azooKey

[English](README.md) | 日本語

azooKeyは、iPhone・iPad向けのカスタマイズ可能な日本語キーボードです。高精度な日本語変換、ライブ変換、カスタムキー、カスタムタブを組み合わせ、自分の入力スタイルに合わせたキーボードを作れます。

[App StoreでazooKeyを入手](https://apps.apple.com/jp/app/azookey-%E8%87%AA%E7%94%B1%E8%87%AA%E5%9C%A8%E3%81%AA%E3%82%AD%E3%83%BC%E3%83%9C%E3%83%BC%E3%83%89%E3%82%A2%E3%83%97%E3%83%AA/id1542709230)

## 主な機能

- ニューラル変換システムZenzaiを含む、かな漢字変換
- 入力中のライブ変換
- カスタムキー・カスタムタブ
- iPhone・iPadに対応
- [AzooKeyKanaKanjiConverter](https://github.com/azooKey/AzooKeyKanaKanjiConverter) として公開されている変換エンジン

macOS版は [azooKey-Desktop](https://github.com/azooKey/azooKey-Desktop) で公開しています。

## コミュニティとベータ版

質問、機能要望、開発相談は [azooKey Discordコミュニティ](https://discord.gg/dY9gHuyZN5) で受け付けています。開発中のビルドは [TestFlight](https://testflight.apple.com/join/x6TKEeB2) から利用できます。

## ビルド

無料のApple Developerアカウントと最新のXcodeが必要です。

```bash
git clone https://github.com/azooKey/azooKey --recursive
open azooKey/azooKey.xcodeproj
```

初回起動後は、アプリ内の案内に従ってキーボードを有効にしてください。開発へ参加する場合は [`docs/CONTRIBUTING.md`](docs/CONTRIBUTING.md) を読み、大きな機能はPull Requestの前にIssueで相談してください。
